# Public gallery fixtures

`AndroidGalleryTest` uses a clean emulator and these openly licensed images. It rejects a personal Plex session or an existing manual location, saves/restores preferences and never runs on a physical television. The literal demo marker is not an authentication credential.

The screenshots are real native Vela views with explicit demo metadata. See [credits](../../gallery/CREDITS.md) and `assets/sources.json`. Fixture images are packaged only in the instrumentation test APK. Production builds include only `app/assets`.
