# Vela, on a real television

A **5-minute continuous walkthrough** of Vela Full on a TCL Android TV: Home, Continue watching, Recently added, Movies, Series, library filters, the programme guide, future programme actions, channel controls, favourites, What to watch, apps, HDMI and integrated settings.

**[Watch or download the full video](vela-continuous.mp4)** · [Download Vela](https://github.com/LucasLG92/vela-tv/releases/tag/v1.38.3-preview) · [Vela Lite](../../lite/README.md)

[![Vela running on a real TCL](preview.jpg)](vela-continuous.mp4)

This is one real-time screen recording of the installed **1.38.2-preview** release, with Spanish menus. It has no cuts, slides, added soundtrack or speed changes. The new 1.38.3 preview adds the compact weather alignment and shorter empty programme widget shown in the current screenshot galleries.

The video includes the live guide and player controls. **The channel picture is not visible in this TCL capture**; the black player area is a recording limitation and is not presented as captured broadcast footage. Stream connection and fallback messages are preserved as recorded. Antenna reception, unlinked accounts and unsupported hardware are not demonstrated.

The owner's profile image, server display name, library artwork and chosen weather city appear with permission. Account and source configuration screens, passwords, tokens, pairing codes and provider credentials are excluded.
