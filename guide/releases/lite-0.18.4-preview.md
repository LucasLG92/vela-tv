# Vela Lite 0.18.4 Preview · Clearer search, quieter voice

A compatibility update for the original separate Lite package.

- Use a compact microphone capsule when the sidebar is hidden or covered, with no detached full-height outline. Keep the exterior halo on the real sidebar when available, including expanded navigation and reduced motion.
- Show channel logos and programme images supplied by antenna/guide data in search. Load the displayed page only and release its image work on pause or navigation.
- Clear the previous programme image when a card is rebound and fit localised AM/PM labels inside the clock widget.

**New installations should use [unified Vela 2.2.1](https://github.com/LucasLG92/vela-tv/releases/tag/v2.2.1-preview) and choose Lite.** Android 8+ is supported. Existing standalone Lite installations can use this compatibility APK and the explicit migration flow; account credentials are excluded from portable migration.

The standalone APK remains free of Plex, Jellyfin, Xtream and the Full playback engine. Shared search/voice behaviour is exercised in unified Lite on an owned Android 8 emulator; package isolation is checked separately. Screenshots and tests use demonstration data. Physical remote-microphone validation remains device-dependent.
