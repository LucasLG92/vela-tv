# Vela 2.2.1 Preview · Search with a clearer picture

Find a title by its poster, recognise a channel by its logo, and use voice search wherever you are in Vela.

- **Voice that follows your screen.** The exterior halo follows the visible sidebar. Full-screen and modal views use a compact microphone capsule, with no stray vertical outline. Reduced motion remains supported.
- **Real images in search.** Plex/Jellyfin posters, channel logos and programme artwork replace generic result icons when the source supplies an image. Only the displayed page loads artwork; Full shares Home's existing cache.
- **More reliable artwork loading.** Abandoned requests no longer fill the work queue. Corrupt cache entries can recover, simultaneous writers cannot overwrite a shared temporary file, and old requests cannot take over a newer selection.
- **Less unnecessary image memory.** Artwork fits its requested display bounds while preserving aspect ratio and transparency. In a controlled native-emulator test, a 180×270 poster used 194,720 bytes rather than 393,536. This measures one decoded image, not total application RAM. [Measurements](https://github.com/LucasLG92/vela-tv/blob/main/guide/OPTIMIZATION.md).
- **Small fixes that matter.** Programme cards drop the previous image when rebound, unchanged bindings are reused, and localised AM/PM labels fit the clock widget.

## Install or update

Use **System → Updates → Check for updates** in Vela, or install the attached official APK over the existing app. Your configuration stays in place. Android asks you to confirm installation.

One APK includes both modes: **Full on Android 11+; Lite on Android 8+**. Lite uses HDMI, antenna TV and apps; media-server clients stay inactive.

Native tests cover Full on API 36 and unified Lite on API 26, actual result artwork, D-pad navigation and paging, hidden/expanded/modal voice geometry, reduced motion and teardown. Screenshots use demonstration data and original artwork; private accounts, credentials and media files are not included. Physical microphone availability still depends on Android and the remote.
