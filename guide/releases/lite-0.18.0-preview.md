# Vela Lite 0.18 Preview · Move to one Vela

This is the transition update for the old **tv.vela.launcher.lite** app. **New installations should download Vela 2.0 and choose Lite.**

Update the old app to this release, install the unified Vela APK once, and choose **Import current Lite profile** on its mode screen. The old app asks for confirmation before granting a temporary, one-use read of its credential-free settings. Your old app and its data remain installed.

The import retains supported layout, appearance, remote shortcuts, antenna favourites and guide corrections. It does not transfer accounts, passwords, PINs, pairing secrets or cached viewing data. The settings PIN must be unlocked before exporting.

This release also shares the refined Vela voice-search interface, with its smaller microphone and responsive accent glow. Android 8+ remains supported.

After checking the unified app and selecting **Vela** as Android's Home, you can remove the old Lite app yourself. From then on, both modes use the **same Vela APK and update channel**.
