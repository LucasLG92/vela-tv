# Vela Lite 0.17.2 Preview · Small details, a calmer home

- Align the weather symbol on the left, with temperature and location in one clear column on the right.
- Shorten the empty programme widget to **Upcoming**, translated into all six menu languages. A followed programme still shows its real title.
- Keep the clock time-only and the same compact widget dimensions. No extra service, timer, worker, view or image cache.
- Preserve existing accounts, favourites, shortcuts and appearance choices when updating.

Lite remains focused on HDMI, antenna television and installed apps; it does not include IPTV or media-server clients.

Install over your existing edition using the signed APK below or check for updates within Vela. Android still requires installation confirmation.
