# Vela Lite 0.18.1 Preview · A quieter way to find it

The standalone Lite transition app receives the shared fluid sidebar feedback and dedicated Search surface, including remote navigation, result filters, reduced motion and a per-profile voice result preference. The expanded sidebar keeps the light aligned. Permission and error recovery remain inside Vela; Android supplies speech recognition.

HDMI, antenna and apps stay lightweight, with no IPTV engine or media-server clients added. This release preserves the explicit, same-signer private migration path to unified Vela. New users should install the unified APK and choose Lite. Existing standalone users can update this app before importing their current profile.
