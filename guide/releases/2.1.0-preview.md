# Vela 2.1 Preview · Find it, then settle in

- Fluid, voice-responsive light follows the real sidebar, including its expanded drawer. The small microphone stays in place. No listening panel or Home dimming; processing settles and fades into the result. Reduced motion stays static.
- A dedicated Search surface, two-column remote navigation, filters and local pages. Show results or open the first ranked voice match, saved per profile. Keyboard searches always show the chooser.
- Search all accessible Plex/Jellyfin movie and series libraries in bounded server pages, independently of how many sections exist. Explicit spoken service names are understood. Guide/provider failures leave other results available and show a partial-source notice.
- Large Xtream catalogues can finish importing on slower devices: CPU time spent encrypting/indexing no longer consumes the network-read budget. Categories are usable before import completes. Responses, disk usage and retained metadata stay bounded; cancellation rolls back an incomplete import.

The unified APK offers Lite on Android 8+ and Full on Android 11+. Existing accounts, profiles, mode and settings remain in place. Native Full/Lite regressions cover voice, remote focus, result paging, source isolation and import budgets. A physical Android 14 box completed a 17,664-channel catalogue import; playback verification is recorded separately. Screenshots use demonstration data, with synthetic speech levels. Android supplies speech recognition; no audio or transcript is stored by Vela.
