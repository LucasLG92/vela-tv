# Vela 2.0 Preview · One app, your choice

Install one APK and choose **Full** or **Lite** on first launch. Change modes later in Settings → System → Launcher mode, with your profiles, linked accounts and preferences kept in place.

- **Full:** Plex, Jellyfin, IPTV, antenna, HDMI and apps, on Android 11+.
- **Lite:** HDMI, antenna and apps, on Android 8+. The cinema Home, library clients and Full screensaver remain inactive.
- **A Home for each profile:** choose its library source, arrange and resize rows, add latest movies, latest series, unwatched or top-rated films, and pin up to six collections.
- **Smoother navigation:** a brief transition keeps row changes readable and respects reduced motion.
- **Vela voice search:** assign a remote or keyboard button; a compact microphone and soft, accent-coloured light show when Vela is listening. Transcription uses Android's available speech service.
- **A safe route from standalone Lite:** install Lite 0.18.0's migration helper, then import its current credential-free profile with explicit confirmation.

Existing Full installations keep their current mode automatically. Android 8–10 offers Lite and explains the Full requirement. Both modes update from the same signed Vela release.

Native first-run, switching, HOME routing, profile/account retention, private migration and voice checks run on owned emulators. Screenshots use demonstration data. Hardware-specific HDMI, antenna and microphone behaviour still needs the relevant TV's support.
