# Vela Lite 0.14.1 Preview

A calmer home for your HDMI devices, antenna television and apps.

- Recent activity moves into Apps, with explicit remote routes and a direct return to your last available activity.
- A neutral profile symbol replaces the sidebar logo. Settings carries the only in-app Vela mark, with a refined native vector.
- Personalisation shows the active profile; settings and tools keep a continuous full-screen background.
- Cleaner settings, scrollable options, preserved remote focus, Cinema/Compact/Minimal styles, readable programme details and optional EPG artwork.
- Guide and logo corrections retain the current channel as metadata arrives; Back/Right return to the selected control.
- Shared playback controls reuse their rows. Lite keeps its independent tuner runtime, with no IPTV, Plex, Jellyfin or Media3 engine.

Download **Vela-Lite-0.14.1-preview.apk** below. Requires **Android 8.0+**. Install Lite on the television that supplies HDMI and antenna inputs. Existing installations can check Settings → Updates. Android asks you to confirm installation.

The APK retains the official Vela signing identity. Its SHA-256 checksum is attached. Public screenshots use synthetic profiles and device/tuner fixtures. No personal account, provider credentials or location is included.
