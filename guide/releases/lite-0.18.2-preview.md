# Vela Lite 0.18.2 Preview · Light around the edges

Voice feedback now uses a soft exterior contour around the actual sidebar, including its expanded view. The interior stays clear and the small microphone remains neutral. Speech response, reduced motion, cancellation and the foreground-only microphone lifecycle are preserved. No media-server client, IPTV engine or background service is added to standalone Lite.

This transition update retains private, explicit migration to the unified Vela APK. New users should install unified Vela and choose Lite; existing standalone installations can update this package first. Both packages retain the established signing identity.
