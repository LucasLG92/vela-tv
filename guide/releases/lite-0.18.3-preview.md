# Vela Lite 0.18.3 Preview · A Home of your own

This compatibility update is for existing installations of the separate Lite app. New installations should use [unified Vela 2.2](https://github.com/LucasLG92/vela-tv/releases/tag/v2.2.0-preview) and choose Lite.

- Edit your HDMI, antenna and Apps destinations in an integrated Home editor.
- Rename, resize, show, hide and reorder them within each profile. Hold OK to move, use the arrows and press OK to place; Back undoes that move.
- Keep a complete draft with fixed Save and Cancel controls. Saved names appear in the sidebar and travel with credential-free settings backups and sync.
- Preserve the native Lite guide, HDMI, voice, updates and explicit one-time profile import into unified Vela. Media-server feeds are not activated in Lite.

The editor uses a recycled native list, without artwork previews or a new background service. Native Android 8 and Android 16 checks cover remote navigation to Save, reorder/undo, cancellation, saved names and profile isolation with demonstration data.
