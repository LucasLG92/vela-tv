# Vela Lite 0.18.5 Preview

Compatibility update for the separate legacy Lite package. Shared preference backups recognise validated playback choices from Full without starting or including its network player. Shared menus retain six-language parity.

Existing HDMI, native antenna TV, guide, profiles and automatic update settings stay in place. Full-only M3U/Xtream playback features are not added to Lite. New installations should use the unified Vela APK and choose Lite.

Install this APK over the separate Vela Lite package; Android asks for confirmation.
