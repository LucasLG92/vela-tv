# Vela 1.37.1 Preview · Reliable live pause startup

Fix live-channel startup when local live pause is enabled and the HLS provider redirects to a media server. Vela now follows bounded HTTP(S) media redirects and resolves playlists, initialisation files and segments against the final playlist address.

- Handles absolute and relative redirects, including the HTTPS-to-HTTP media hand-off used by some IPTV providers. Account API transport and TLS verification are unchanged.
- Keeps existing disk, segment and duration limits; adds no permission, service or parallel player.
- Rejects redirect loops, excessive hops and unsupported URL schemes.
- Retains accounts, profiles, channel lists, favourites and remote shortcuts.

A native regression reproduces the old failure and passes after the fix, covering playlist and segment redirects, final URI resolution and buffer cleanup. The correction was also checked on the affected TCL with local live pause enabled.

Vela Lite is unchanged at 0.16.0; it does not use this IPTV buffer.
