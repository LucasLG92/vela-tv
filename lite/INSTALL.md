# Use Vela Lite

Download the [unified Vela APK](https://github.com/LucasLG92/vela-tv/releases/tag/v2.0.0-preview), install it and choose **Lite** on first launch. Android 8.0+ is supported. The Full option requires Android 11+.

Open **Settings → System → Home screen** and select **Vela** as Android’s Home. HDMI and antenna playback depend on the inputs and tuner exposed by your television.

Already using the separate **Vela Lite** app? Update it to [0.18.0 Preview](https://github.com/LucasLG92/vela-tv/releases/tag/lite-v0.18.0-preview), then use **Import current Lite profile** in the unified app. The old app asks for confirmation. Check the new app and its Home selection before uninstalling the old one.
